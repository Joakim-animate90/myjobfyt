**MJF-064**

## Problem

There is no operational visibility. A failed CV parse or a stuck submission cannot be diagnosed.

## Business impact

Without this, every production problem is a guess, and candidate-reported issues cannot be investigated.

## Technical impact

Platform metrics, queue and stream health, per-source discovery health, AI spend, worker execution, and a trace view reconstructing one workflow from a correlation id with timestamps, durations and errors at every hop.

## Proposed solution

Build the admin surface with every number linking through to its underlying records. The trace view correlates OpenTelemetry traces with the application event log and Loki logs. PII is masked by default and unmasking is a separately audited action.

## Acceptance criteria

- [ ] An administrator can trace a CV upload through every stage with timestamps and durations
- [ ] Dead-letter queues are visible with the full envelope and a requeue action
- [ ] AI token spend is visible per purpose and per user
- [ ] PII is masked by default; unmasking is audited
- [ ] No CV content, password, token or prompt body appears anywhere in the admin UI or its logs

## Testing requirements

A test asserting a correlation id reconstructs a full chain. A redaction test across every admin view.
