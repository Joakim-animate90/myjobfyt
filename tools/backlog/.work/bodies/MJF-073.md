**MJF-073**

## Problem

There is no path from a bare VPS to a running cluster.

## Business impact

Blocks the initial deployment target.

## Technical impact

Idempotent scripts for SSH hardening, firewall, users and permissions, unattended security updates, Docker, k3s, Flux bootstrap, backups and cluster health checks.

## Proposed solution

Write each script to be safe, documented and idempotent, with a dry-run mode. SSH hardening disables password authentication and root login. Backups cover Postgres and object storage with a tested restore procedure.

## Acceptance criteria

- [ ] Every script is idempotent and safe to re-run
- [ ] A dry-run mode shows what would change without changing it
- [ ] SSH hardening disables password and root login
- [ ] The firewall defaults to deny inbound except SSH, HTTP and HTTPS
- [ ] Backups are scheduled and the restore procedure is documented and tested
- [ ] No secret is written to disk in plaintext

## Testing requirements

Run each script twice against a fresh VM asserting the second run is a no-op. Perform an actual restore from backup.
