**MJF-022**

## Problem

Remote roles are a large share of candidate demand and these feeds are public, free and require no credentials.

## Business impact

Cheap breadth for the most-requested search type.

## Technical impact

Three simple JSON feed adapters with no authentication.

## Proposed solution

Implement against the public feeds, declaring remote_only in capabilities so the planner does not waste calls on location-bound searches.

## Acceptance criteria

- [ ] Each adapter returns postings and maps them to the canonical shape
- [ ] Capabilities correctly declare remote_only
- [ ] A feed outage degrades the run only

## Testing requirements

Fixture conformance tests per adapter.
