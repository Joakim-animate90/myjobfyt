**MJF-072**

## Problem

No GitOps. Deployment would be manual and undocumented.

## Business impact

Manual deployment is unrepeatable and unauditable.

## Technical impact

Cluster bootstrap, GitRepository and HelmRepository sources, HelmReleases per environment, Kustomizations, image update automation, health checks and a documented rollback.

## Proposed solution

Structure the Flux repository with clean environment separation. Secrets are SOPS-encrypted with age; nothing is plaintext in Git. Image update automation is scoped to patch tags only, so a major version never deploys itself.

## Acceptance criteria

- [ ] Bootstrap is documented and repeatable from scratch
- [ ] Environments are separated and cannot cross-contaminate
- [ ] No plaintext secret exists anywhere in Git history
- [ ] HelmRelease health checks gate the rollout
- [ ] Rollback is documented and tested
- [ ] Image automation is limited to patch versions

## Testing requirements

A bootstrap test against a kind cluster. A git-history secret scan as a CI gate.
