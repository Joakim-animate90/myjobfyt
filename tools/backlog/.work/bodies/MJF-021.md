**MJF-021**

## Problem

No real job data enters the system. Adzuna is the right first source: a documented public API with self-service credentials, broad country coverage and good salary data.

## Business impact

Validates the entire pipeline end to end with real postings and no partnership negotiation.

## Technical impact

Paginated search across countries, mapping to the canonical raw shape, honouring the documented rate limit.

## Proposed solution

Implement the adapter against the current documented API, verified at implementation time rather than from memory. Record fixtures for the conformance suite.

## Acceptance criteria

- [ ] Search returns real postings for a title and location across supported countries
- [ ] Pagination is resumable from a persisted cursor
- [ ] Salary, employment type and location are mapped to the canonical shape
- [ ] 429 responses honour Retry-After
- [ ] Credentials come from config and are never committed

## Testing requirements

Fixture-based conformance tests: normal page, empty result, malformed field, 429, 500. One manually-run live test behind a build tag.
