**MJF-053**

## Problem

Loops cannot be created or managed without a UI.

## Business impact

The loop wizard is where a candidate's search intent is captured. Getting it wrong produces irrelevant matches.

## Technical impact

The four-step wizard, draft resume, a live email-template preview with real substitutions, a filter impact preview, and lifecycle controls.

## Proposed solution

Build the stepper with per-step validation and preconditions enforced where they apply. Show the filter impact preview ('this would have rejected N of your last 240 postings') so filter tuning is informed. Pause is a prominent, first-class control.

## Acceptance criteria

- [ ] All four steps validate independently and the draft resumes
- [ ] The email template preview shows real substituted values
- [ ] The filter editor shows the impact of a change before saving
- [ ] Pause is prominent and takes effect visibly
- [ ] An edit shows a clear 'takes effect next run' notice
- [ ] Entitlement limits are explained at the point of friction with an upgrade path, never a dead end

## Testing requirements

Wizard tests for each step's validation and for draft resume. A test asserting the pause control reflects server state.
