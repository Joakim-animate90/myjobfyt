**MJF-009**

## Problem

Semantic title and skill matching needs embeddings, and matching must keep working when the embedding provider does not.

## Business impact

Semantic matching is what makes a 'Go developer' CV match a 'Backend Engineer (Golang)' posting.

## Technical impact

Generate title, skills and summary embeddings per CV version; store in cv_embeddings; provide cosine similarity and a lexical fallback.

## Proposed solution

Add an Embedder to the AI platform package. Persist vectors with their model and dimensions so a model change is detectable. When unavailable, fall back to trigram/token similarity and mark affected matches scoring_mode=degraded for later rescoring.

## Acceptance criteria

- [ ] Embeddings are generated for each CV version and stored with model and dims
- [ ] Cosine similarity is correct against known vectors
- [ ] With the provider down, matching continues lexically and matches are marked degraded
- [ ] Degraded matches are rescored when the provider recovers
- [ ] A match is never dropped because scoring was degraded

## Testing requirements

Unit tests for cosine similarity and the fallback. An integration test forcing provider failure and asserting matches are still produced and marked.
