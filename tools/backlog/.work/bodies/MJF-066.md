**MJF-066**

## Problem

There is no way for a candidate to export or erase their data, which is a legal obligation for a platform holding CVs and application history.

## Business impact

A non-negotiable legal requirement, and a trust signal.

## Technical impact

An export job assembling per-table JSON plus original CV files; a 7-day grace period; an idempotent resumable erasure job with a verification pass.

## Proposed solution

Implement both as resumable idempotent jobs. Deletion halts automation immediately while leaving sign-in available during the grace period, so a candidate can cancel. The erasure verification pass fails loudly rather than reporting a partial erasure as complete.

## Acceptance criteria

- [ ] Export covers every table holding the candidate's data plus their CV files
- [ ] Export links are single-use with a one-hour TTL and bound to the requesting session
- [ ] Automation halts immediately on a deletion request; sign-in continues during grace
- [ ] Erasure is resumable and idempotent
- [ ] A verification pass confirms completeness and fails loudly if not
- [ ] Deletion is available on every tier

## Testing requirements

An export completeness test enumerating every table with a user_id column. An erasure test asserting the verification pass catches an induced partial erasure.
