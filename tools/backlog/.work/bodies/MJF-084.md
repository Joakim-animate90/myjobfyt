**MJF-084**

## Problem

No automated security scanning exists, so a vulnerable dependency or a committed secret would go unnoticed.

## Business impact

This platform holds CVs, phone numbers, application history and SMTP credentials. A disclosure would be material.

## Technical impact

govulncheck, npm audit, Trivy for containers, gitleaks across history, CodeQL, and Dependabot.

## Proposed solution

Add all scanners to CI as gates. Secret scanning covers the full history, not just the diff, since the repository is public.

## Acceptance criteria

- [ ] A dependency vulnerability of high severity or above fails the build
- [ ] A container vulnerability of high severity or above fails the build
- [ ] Secret scanning covers the entire git history
- [ ] SAST runs on every pull request
- [ ] Dependabot is configured for Go, npm and Actions
- [ ] Every finding is triaged, not merely reported

## Testing requirements

Introduce a known-vulnerable dependency and a fake secret and confirm each is caught.
