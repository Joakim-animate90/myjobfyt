**MJF-052**

## Problem

CV management is the candidate's main lever on match quality and there is no interface for it.

## Business impact

A badly parsed CV produces bad matches. The review screen is how a candidate fixes that themselves.

## Technical impact

Drag-and-drop upload with progress, live parse status, a field-level parse review with provenance, the CV checker dashboard, and per-CV performance stats.

## Proposed solution

Build the library grid, the upload flow with pre-upload type and size feedback, and the parse-review screen showing confidence and letting the candidate correct fields — corrections being permanently authoritative. The checker shows sub-scores and anchored recommendations.

## Acceptance criteria

- [ ] Upload shows progress and rejects wrong types before uploading
- [ ] Parse status is live, naming the current stage rather than showing a bare spinner
- [ ] Low-confidence fields are visibly flagged and editable
- [ ] The checker shows per-category sub-scores and location-anchored recommendations
- [ ] Per-CV stats withhold a verdict below the minimum sample and say so

## Testing requirements

Component tests for each upload failure mode. A test asserting the 'not enough data' state appears below the sample threshold.
