**MJF-080**

## Problem

There is no CI. Nothing stops a broken commit reaching main.

## Business impact

Every defect that reaches main costs more to find than one caught in CI.

## Technical impact

GitHub Actions running gofmt check, go vet, golangci-lint, unit tests with -race, coverage reporting, migration validation, frontend lint, typecheck and tests.

## Proposed solution

Implement CI with caching, running the backend and frontend jobs in parallel. Migration validation runs without a database so it needs no service container.

## Acceptance criteria

- [ ] Every push and pull request runs the full suite
- [ ] Tests run with -race
- [ ] A formatting or vet failure blocks the merge
- [ ] Coverage is reported per package
- [ ] The pipeline completes in under 10 minutes
- [ ] Migration validation requires no database

## Testing requirements

Verify each check fails the build when deliberately broken.
