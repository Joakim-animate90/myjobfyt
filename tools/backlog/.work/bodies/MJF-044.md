**MJF-044**

## Problem

Forms ask screening questions that block submission, and some of those questions must never be answered by a machine.

## Business impact

An AI-answered disability or visa question is a discrimination-exposure problem for the candidate and the platform.

## Technical impact

A questions queue, similarity-matched saved answers, AI drafting for non-sensitive questions on higher tiers, and hard refusal for sensitive categories.

## Proposed solution

Implement the queue and saved-answer reuse by normalised question similarity. AI answers draw only on the parsed CV, profile and previous answers; anything unsupported is escalated, never guessed. Sensitive categories are always escalated — the app_questions_sensitive_never_ai constraint enforces it in the database too.

## Acceptance criteria

- [ ] Nothing is submitted while required questions are pending
- [ ] Saved answers are reused across applications by question similarity
- [ ] Sensitive categories are never auto-answered on any tier
- [ ] An AI answer unsupported by profile data escalates instead of guessing
- [ ] Saved answers are viewable and editable
- [ ] Question text is treated as untrusted input in prompts

## Testing requirements

A sensitive-category detection suite across phrasings and languages. A test asserting an unsupported claim escalates. Injection tests on question text.
