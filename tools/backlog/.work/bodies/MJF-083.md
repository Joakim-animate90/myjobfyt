**MJF-083**

## Problem

There is no deployment pipeline, and CI and CD must be separate so untested code cannot reach production.

## Business impact

An untested production deployment is the most expensive kind of mistake.

## Technical impact

Image build and publish on a green CI run, a deployment-configuration update, Flux reconciliation, health gating, and documented rollback.

## Proposed solution

Separate CD from CI. Images are built only from a commit whose CI passed. Staging deploys automatically; production requires a manual approval. Failed health checks block promotion.

## Acceptance criteria

- [ ] CD runs only after CI passes on the same commit
- [ ] Images are tagged with the commit SHA, never only latest
- [ ] Staging deploys automatically; production requires approval
- [ ] A failed health check blocks promotion and alerts
- [ ] Rollback is one documented, tested action
- [ ] Failed checks make production deployment impossible, not merely discouraged

## Testing requirements

A deliberately failing deployment asserting promotion is blocked and rollback succeeds.
