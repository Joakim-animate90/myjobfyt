**MJF-070**

## Problem

Nothing is containerised, so nothing can be deployed.

## Business impact

Blocks every deployment.

## Technical impact

Multi-stage builds, non-root users, minimal base images, embedded migrations, and reproducible builds.

## Proposed solution

One multi-stage Dockerfile per binary with a distroless or minimal runtime, running as non-root with a read-only root filesystem. Migrations are embedded so the migration job provably runs the SQL built from that commit.

## Acceptance criteria

- [ ] Images run as a non-root user with a read-only root filesystem
- [ ] Final image size is under 50MB per binary
- [ ] Builds are reproducible for a given commit
- [ ] The migrate image contains the embedded migrations
- [ ] A container security scan reports no high or critical findings

## Testing requirements

Build and run each image. Trivy scan in CI as a gate.
