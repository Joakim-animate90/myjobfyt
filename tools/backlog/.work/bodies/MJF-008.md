**MJF-008**

## Problem

Candidates need concrete, actionable feedback on their CV. Generic advice is worthless and an opaque score is worse.

## Business impact

A free-tier acquisition feature and a genuine differentiator, but only if the advice is specific.

## Technical impact

Deterministic checks (length, sections present, contact detectable, date-format consistency, bullet density, ATS-parseability) combined with an LLM pass for impact and keyword coverage, feeding one documented scoring rubric.

## Proposed solution

Implement the rule layer first so a score exists without the AI. Add the LLM pass for impact and missing keywords. Every recommendation is anchored to a specific location in the CV. Cache by version hash plus target role.

## Acceptance criteria

- [ ] The same CV always produces the same score
- [ ] Sub-scores are reported per category, not just an overall number
- [ ] Every recommendation names a specific location in the CV
- [ ] With the AI provider down, the deterministic subset is returned and the response states what is missing
- [ ] A fabricated score is never returned

## Testing requirements

Rubric unit tests per category. A snapshot test proving determinism. A degraded-mode test asserting the response declares its own incompleteness.
