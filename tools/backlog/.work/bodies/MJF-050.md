**MJF-050**

## Problem

There is no frontend. The API is unusable by a candidate.

## Business impact

Without a UI there is no product, only an API.

## Technical impact

Next.js App Router with TypeScript, Tailwind and shadcn/ui, a React Query provider, a typed API client with Zod validation, and design tokens.

## Proposed solution

Scaffold the application with the conventions in CLAUDE.md: server components by default, all server state through React Query, every payload validated by a Zod schema so a contract mismatch surfaces as a clear error rather than rendering as blank.

## Acceptance criteria

- [ ] make fe-typecheck and make fe-lint pass
- [ ] Design tokens are defined; no hardcoded colours in components
- [ ] The API client attaches the access token and refreshes once on 401 with single-flight dedupe
- [ ] A Zod validation failure produces a visible, actionable error
- [ ] Dark mode works

## Testing requirements

Component tests for the API client's refresh path, including concurrent 401s collapsing into one refresh.
